# Оформление Telegram-бота

Гостевые сообщения оформлены в сдержанном стиле ресторана: название, подпись «На берегу Волги · Самара», тёплый тон, короткие заголовки и компактные кнопки. Telegram определяет цвет кнопок, фон и шрифт в соответствии с приложением/темой самого гостя. Код не обещает принудительно изменить эти цвета.

## Приветствие

**Дети лейтенанта Шмидта**  
*На берегу Волги · Самара*

Добро пожаловать на борт.

Волжское гостеприимство начинается со знакомства. Здесь удобно выбрать блюда, перейти к доставке и узнать о предложениях ресторана.

**Начнём со знакомства?**

Для регистрации нужно ваше согласие на обработку данных. Рекламная подписка подключается отдельно и только по желанию.

Далее отображается **действующий текст PD_TEXT владельца без изменения содержания** и две кнопки: «Согласен на обработку данных» / «Продолжить без регистрации».

Следующий экран «Оставаться на связи?» отдельно показывает действующий MARKETING_TEXT и предлагает «Да, получать акции и рекламу» / «Продолжить без рекламы». Реклама не подключается автоматически. Версии документов сохраняются в истории согласий и доступны через `/privacy`, но не загромождают приветствие.

Повторный `/start` зарегистрированного гостя открывает главное меню с текстом «С возвращением на борт». Согласия повторно не запрашиваются и подписка не восстанавливается.

## Кнопки

| Левая | Правая |
|---|---|
| ✦ Акции | 🍽 Меню |
| 🚘 Доставка | ⌖ Контакты |
| Моя подписка | |

Если URL настроен, соответствующая кнопка сразу открывает ссылку. При пустом URL показывается честное сообщение о ненастроенной ссылке. Старые сообщения с callback-кнопками продолжают работать. На информационных экранах есть возврат в главное меню. Старые сообщения в истории Telegram не переписываются.

## Свой текст без изменения Python

В существующую локальную `.env` можно добавить:

```dotenv
WELCOME_TITLE="Дети лейтенанта Шмидта"
WELCOME_TEXT="Добро пожаловать на борт.\n\nВолжское гостеприимство начинается со знакомства. Здесь удобно выбрать блюда, перейти к доставке и узнать о предложениях ресторана."
```

Это обычный текст: HTML-теги не нужны. `\n` внутри двойных кавычек файла `.env` превращается в перенос строки. Заголовок ограничен100 символами, приветствие600. Переменные окружения Windows имеют приоритет над `.env`. Без этих переменных используются готовые тексты из кода.

WELCOME_* не относятся к документам согласий: их изменение не изменяет PD/MARKETING и не требует новой версии согласия. Для самой правки юридического документа сохраняется прежнее правило новой версии. `MARKETING_VERSION` — короткая метка вроде `marketing-v1`, а не весь текст согласия.

## Аватар и описание профиля через BotFather

Эти действия владелец выполняет вручную в **@BotFather**, выбрав своего бота. Разработчик настройки профиля не менял и внешние API не вызывал.

1. `/setname` — «Дети лейтенанта Шмидта».
2. `/setuserpic` — загрузите квадратную картинку с действующим логотипом ресторана. Центральная часть должна читаться в круглом маленьком аватаре; не растягивайте широкий логотип целиком в квадрат.
3. `/setabouttext` — короткое описание:

   > Ресторан на берегу Волги в Самаре. Меню, доставка, контакты и предложения для гостей.

4. `/setdescription` — описание перед первым запуском:

   > Добро пожаловать в «Дети лейтенанта Шмидта». Волжское гостеприимство — всегда рядом: выбирайте блюда, переходите к доставке и находите дорогу к ресторану. Рекламные предложения — только по вашему согласию. Нажмите «Запустить», чтобы познакомиться.

Токен менять ради оформления не требуется. Не отправляйте его в чат или скриншотах. В этой задаче изображения не генерировались и не отправлялись, описание и аватар не применены автоматически.

## Как применить обновление к уже работающему боту

1. Остановите программу Ctrl+C и сделайте резервную копию штатной командой из README.
2. Обновите `bot.py` и каталог `restaurant_bot/` из подготовленной версии. Для воспроизводимой установки сохраните также `requirements.txt`, README и тесты.
3. **Сохраните свою `.env`, `.venv`, папки data/backups и выбранную базу.** Не заменяйте `.env` примером. Новые WELCOME_* необязательны, текущие токен/ID/согласия продолжают использоваться.
4. Запустите обычной командой `.\.venv\Scripts\python.exe bot.py`.
5. В Telegram отправьте `/start`, чтобы получить обновлённое меню. История старых сообщений останется прежней.

Протестированы тексты, безопасное HTML-форматирование, ссылки и совместимость обработчиков в локальном sandbox. Проверка настоящего отображения на iPhone/Android выполняется владельцем после обновления; разработчик не подключал Telegram и не делал отправок.
