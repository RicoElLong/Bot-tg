# Telegram-бот ресторана «Дети лейтенанта Шмидта»

## Настройка

1. Создайте виртуальное окружение Python и установите зависимости: `pip install -r requirements.txt`.
2. Скопируйте `.env.example` в `.env` на компьютере или сервере, где запускается бот.
3. Запишите действующий токен BotFather в `BOT_TOKEN` локального `.env`. Не публикуйте этот файл и не вставляйте токен в код, сообщения, скриншоты или команды терминала.
4. Запустите `python bot.py`.

## После утечки токена

- Сначала отзовите старый токен через `/revoke` в официальном @BotFather и получите новый.
- Остановите старый процесс бота, замените токен только в локальном окружении запуска и запустите одну копию бота.
- Проверьте имя, описание, фотографию, команды и кнопку меню бота через @BotFather; восстановите изменённые параметры по подтверждённым материалам владельца.
- Если использовался посторонний webhook, удалите его через доверенный Telegram Bot API клиент с новым токеном перед запуском polling. Не передавайте новый токен сторонним сайтам.
- Проверьте `/start` со своего Telegram-аккаунта.

Файл `.env` удалён из текущей версии репозитория, но прежние версии остаются в истории Git. Удаление файла не отзывает токен. Старые ключи следует считать скомпрометированными независимо от последующей очистки истории. Не восстанавливайте старый `.env` из истории.

Текущая версия содержит приветствие по `/start`. CRM, рассылки и рабочая выдача призов рулетки в этом репозитории пока не реализованы.
