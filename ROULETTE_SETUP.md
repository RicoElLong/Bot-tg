# Вкусная рулетка — технический MVP

Это **демонстрационная** Telegram Mini App. Она отображает анимированное колесо и получает результат с сервера, но **не выдаёт реальные призы, скидки или промокоды**.

## Что реализовано
- Проверка подписи Telegram \`initData\` и срока действия (1 час).
- Доступ только для пользователей, зарегистрированных в таблице \`guests\` бота.
- Атомарное сохранение **одного** демонстрационного вращения на пользователя в SQLite; повторный запрос возвращает прежний результат.
- Серверное случайное определение сектора (пока равные вероятности).
- Адаптивная страница рулетки.

## Локальный запуск
1. Обновите репозиторий и установите зависимости: \`py -m pip install -r requirements.txt\`.
2. Сохраните секреты в локальном \`.env\`: \`BOT_TOKEN\` и при необходимости \`BOT_DB_PATH\`. Файл \`.env\` не коммитить.
3. Запустите бота: \`py bot.py\`.
4. Во втором окне запустите API: \`py -m uvicorn roulette_api:app --host 127.0.0.1 --port 8000\`.
5. Для Mini App нужен **публичный HTTPS URL**, указывающий на API и страницу; локальный адрес \`127.0.0.1\` в Telegram не подходит. Для разработки используйте доверенный HTTPS-туннель; для продакшена — VPS с HTTPS.
6. Укажите \`ROULETTE_WEBAPP_URL=https://ваш-домен/\` в локальном \`.env\` и перезапустите бота.

## Важно до публичного запуска
- Нужны утверждённые правила акции, реальные призы, вероятности, лимиты и серверная выдача/погашение промокодов.
- Еженедельные попытки со случайным временем в рабочие часы Самары и уведомления **ещё не реализованы**.
- Не храните базу с персональными данными в публичной директории. Защитите доступ, резервные копии и сервер.
- Рекламные рассылки отключены без отдельного надлежащего согласия.
- Для публичного развёртывания необходимы HTTPS, ограничения запросов, мониторинг и проверка безопасности.
